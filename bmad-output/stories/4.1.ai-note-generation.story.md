> **Cross-epic dependency notice:** 3.3(분석 Job 파이프라인)이 이 스토리의 함수를 호출한다.
> 에픽 번호상 Epic 3보다 뒤지만, 실제로는 3.3보다 먼저 구현되어야 한다.

## Story

As a **사용자(본인)**,
I want **분석된 GitHub 데이터를 기반으로 AI가 학습 노트를 자동 생성하**,
so that **직접 요약·정리하지 않아도 핵심을 파악할 수 있다**.

## Acceptance Criteria

1. `lib/domain/note/note-generator.ts`에 수집된 데이터(README, 디렉토리 구조, 커밋, PR)를 받아
   OpenAI API로 노트(summary, concepts, architecture, learningPoints, rawMarkdown)를 생성하는
   함수가 있다.
2. 커밋/PR 데이터가 존재하면 프롬프트에 포함되어 생성된 노트 내용에 개발 흐름(작업 과정) 관련
   설명이 반영된다.
3. 생성된 노트는 `lib/domain/note/note-service.ts`의 함수로 `notes` 테이블에 저장되고, 저장된
   `noteId`가 반환된다.
4. OpenAI API 호출 실패 시 에러가 throw되어 호출자(3.3의 파이프라인)가 FAILED 처리를 할 수
   있다.

## Testing

- **Approach:** 단위 테스트(OpenAI 클라이언트 mock).
- **Key scenarios:** 정상 생성, 커밋/PR 데이터 있음/없음에 따른 프롬프트 분기, API 실패.
- **Per-AC verification:** AC#1 → mock 응답으로 구조화 결과 필드 확인; AC#2 → 커밋/PR 포함
  fixture와 미포함 fixture의 프롬프트 생성 함수 출력 차이 확인; AC#3 → 저장 함수 호출 후 DB 값
  확인; AC#4 → mock 실패 시 에러 throw 확인.
- **Fixtures / mocks:** OpenAI API mock 응답, 수집 데이터 fixture(README/디렉토리/커밋/PR 조합별).
- **Edge cases to cover:** OpenAI 응답이 기대한 JSON 구조가 아닐 때의 파싱 실패 처리.
