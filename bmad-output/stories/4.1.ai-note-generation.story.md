> 에픽 번호상 Epic 3보다 뒤지만, 실제로는 3.3보다 먼저 구현되어야 한다.

## Story

As a **사용자(본인)**,
I want **분석된 GitHub 데이터를 기반으로 AI가 학습 노트를 자동 생성하**,
so that **직접 요약·정리하지 않아도 핵심을 파악할 수 있다**.

## Acceptance Criteria

1. `lib/domain/note/note-generator.ts`에 수집된 데이터(README, 디렉토리 구조, 커밋, PR)를 받아
   OpenAI API로 노트(summary, concepts, architecture, learningPoints, rawMarkdown)를 생성하는
   함수가 있다.
2. 커밋/PR 데이터가 존재하면 프롬프트에 포함되어 생성된 노트 내용에 개발 흐름(작업 과정) 관련
   설명이 반영된다.
3. 생성된 노트는 `lib/domain/note/note-service.ts`의 함수로 `notes` 테이블에 저장되고, 저장된
   `noteId`가 반환된다.
4. OpenAI API 호출 실패 시 에러가 throw되어 호출자(3.3의 파이프라인)가 FAILED 처리를 할 수
   있다.

## Dev Agent Record

**완료일:** 2026-08-03 (Ralph loop)
**Branch:** `feature/4.1-ai-note-generation` (base: `feature/nextjs-migration`)

**진행 요약:**
- `openai` 공식 SDK 설치. `lib/domain/note/note-generator.ts`의 `generateNote()`가
  `chat.completions.create({model: "gpt-4o", response_format: {type: "json_object"}})`로
  구조화된 JSON을 받아 파싱/검증한다.
- **스키마 갭 발견 및 보완:** AC#1은 생성 필드로 "summary, concepts, architecture,
  learningPoints, rawMarkdown"만 나열했지만, 1.2에서 정의된 `Note.title`은 필수(NOT NULL)
  필드다. AI가 `title`도 함께 생성하도록 프롬프트/스키마에 추가했다 — 그렇지 않으면
  `note-service.ts`가 저장할 title 값이 없어서 막힌다. [Learning]
- 프롬프트는 README/디렉토리 구조를 항상 포함하고, 커밋/PR이 있을 때만 해당 섹션을 추가해
  AC#2("커밋/PR 있으면 개발 흐름 반영")를 충족 — 시스템 프롬프트에도 이 지시를 명시.
- 에러 처리: API 호출 실패/응답 없음/JSON 파싱 실패/스키마 불일치 4가지 케이스 모두
  `NoteGenerationError`로 통일해 throw (3.3이 FAILED 처리할 때 구분 없이 catch하면 됨).
- 단위 테스트 11건 (OpenAI mock — octokit 때와 동일하게 `function MockOpenAI() {...}` 일반
  함수로 mock 구현, 화살표 함수 함정 재발 방지). 통합 테스트 1건은 실제 Neon DB에 저장까지 확인.
  전체 스위트 63건 통과. `npm run build`/`lint` 통과.
- **실제 OpenAI API로도 직접 검증함** (mock이 아닌 진짜 호출) — `.env`에 실제
  `OPENAI_API_KEY`가 있어서, 임시 스크립트로 실제 GPT-4o 호출까지 성공 확인 (커밋 데이터
  포함 시 "marking the starting point" 같은 개발 흐름 설명이 실제로 summary에 반영됨을 확인).
  스크립트는 검증 후 삭제함.

**후속 스토리를 위한 참고:**
- 3.3(파이프라인)이 `generateNote()` → `createNoteFromAnalysis()` 순서로 호출한다.
  `generateNote`가 반환하는 `GeneratedNote`를 그대로 `createNoteFromAnalysis`에 넘기면 된다.
- `lib/domain/note/note-service.ts`는 4.2(조회 함수 추가), 4.3(삭제 함수 추가)이 이어서
  수정한다.
