# 5.3: Markdown export 다운로드

**Story ID:** 5.3
**Epic:** 5 — 블로그 초안 & Export
**Slug:** blogdraft-markdown-export
**Status:** ready-for-dev
**Branch:** `feature/5.3-blogdraft-markdown-export` (base: `feature/nextjs-migration`)

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **사용자(본인)**,
I want **블로그 초안을 Markdown 파일로 내려받**,
so that **내가 원하는 플랫폼에 수동으로 발행할 수 있다**.

## Acceptance Criteria

1. `POST /api/notes/{noteId}/blog-draft/export`는 해당 초안의 `content`를 `.md` 파일로
   스트리밍 응답한다 (`Content-Type: text/markdown`, `Content-Disposition: attachment`).
2. 본인 소유가 아니면 403, 초안이 없으면 404를 반환한다.
3. `/notes/{noteId}` 페이지의 블로그 초안 섹션에 "Markdown 다운로드" 버튼이 있다.

## Testing

- **Approach:** API 통합 테스트(응답 헤더/본문 확인) + UI 수동 다운로드 확인.
- **Key scenarios:** 정상 다운로드, 타인 소유 403, 초안 없음 404.
- **Per-AC verification:** AC#1 → 통합 테스트로 `Content-Type`/`Content-Disposition` 헤더 및
  본문(content 일치) 확인; AC#2 → 타인 소유/초안 없음 케이스 테스트; AC#3 → 수동으로 다운로드
  버튼 클릭 후 파일 저장 확인.
- **Fixtures / mocks:** 테스트 BlogDraft fixture.
- **Edge cases to cover:** 제목에 파일명으로 부적절한 문자(슬래시, 특수문자 등)가 포함된 경우
  slug 처리로 안전한 파일명 생성.
