# 3.5: 내 분석 목록 조회 API + UI

**Story ID:** 3.5
**Epic:** 3 — Repo 분석 (커밋/PR 포함)
**Slug:** analysis-list-api-ui
**Status:** done
**Branch:** `feature/3.5-analysis-list-api-ui` (base: `feature/nextjs-migration`)

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **사용자(본인)**,
I want **내가 요청한 분석 Job 목록을 확인하**,
so that **과거에 어떤 repo를 분석했는지 한눈에 볼 수 있다**.

## Acceptance Criteria

1. `GET /api/analysis`는 본인 소유 Job 목록을 `page`/`size` 쿼리 파라미터로 페이지네이션하여
   반환한다.
2. 목록 항목에는 `jobId`, `repoUrl`, `branch`, `status`, `createdAt`이 포함된다.
3. `/analysis` 페이지에 목록이 표시되고, 각 항목에서 완료된 경우 노트로 이동할 수 있는 링크가
   제공된다.
4. 미인증 요청은 401로 거부된다.

## Testing

- **Approach:** API 통합 테스트 + UI 목록 렌더링 수동 확인.
- **Key scenarios:** 목록 조회, 페이지네이션 동작, 본인 소유만 조회, 미인증 401.
- **Per-AC verification:** AC#1 → 여러 페이지 fixture로 페이지네이션 테스트; AC#2 → 응답 필드
  확인; AC#3 → 수동으로 목록/링크 확인; AC#4 → 미인증 401 확인.
