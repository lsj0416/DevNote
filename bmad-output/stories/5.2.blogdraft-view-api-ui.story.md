## Story

As a **사용자(본인)**,
I want **노트에 연결된 블로그 초안을 조회하**,
so that **AI가 생성한 초안을 확인하고 발행 전에 검토할 수 있다**.

## Acceptance Criteria

1. `GET /api/notes/{noteId}/blog-draft`는 해당 노트의 블로그 초안(title, content)을 반환한다.
2. 본인 소유가 아니면 403, 초안이 없으면 404를 반환한다.
3. `/notes/{noteId}` 상세 페이지에 블로그 초안 섹션(제목/본문)이 표시된다.

## Tasks / Subtasks

- [ ] `GET /api/notes/{noteId}/blog-draft` Route Handler + 소유권 검증 (AC: #1, #2)
- [ ] 노트 상세 페이지에 블로그 초안 섹션 UI 추가 (AC: #3)

## Testing

- **Approach:** API 통합 테스트 + UI 렌더링 수동 확인.
- **Key scenarios:** 정상 조회, 타인 소유 403, 초안 없음 404.
- **Per-AC verification:** AC#1 → 통합 테스트로 title/content 필드 확인; AC#2 → 타인 소유/초안
  없음 케이스 테스트; AC#3 → 수동으로 상세 페이지에 섹션 노출 확인.
- **Fixtures / mocks:** 테스트 BlogDraft fixture(있음/없음).
- **Edge cases to cover:** 초안이 없는 노트 상세 페이지 접근 시 UI가 에러로 깨지지 않고 안내
  문구를 표시.
