# 3.6: repo 분석 요청 UI

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **사용자(본인)**,
I want **repo URL과 브랜치를 입력하는 폼으로 분석을 요청하**,
so that **API를 직접 호출하지 않고도 화면에서 바로 분석을 시작할 수 있다**.

## Acceptance Criteria

1. `/analysis` 페이지에 repo URL 입력 필드와 선택적 브랜치 입력 필드가 있는 폼이 있다.
2. 폼 제출 시 `POST /api/analysis`가 호출되고, 성공 시 새 Job이 목록에 나타나고 상태 폴링이
   시작된다.
3. 잘못된 URL 제출 시(400) 서버 에러 메시지가 화면에 표시된다.
4. 이미 진행 중인 동일 repo 요청 시(409) 사용자에게 안내 메시지가 표시된다.

- **Per-AC verification:** AC#1 → 폼 렌더 테스트; AC#2 → mutation mock 성공 시 목록/폴링 갱신
  확인; AC#3 → 400 mock 응답 시 에러 메시지 렌더 확인; AC#4 → 409 mock 응답 시 안내 메시지 확인.
