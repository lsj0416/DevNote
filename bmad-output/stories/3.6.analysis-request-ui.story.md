# 3.6: repo 분석 요청 UI

**Status:** done
**Branch:** `feature/3.6-analysis-request-ui` (base: `feature/nextjs-migration`)

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As a **사용자(본인)**,
I want **repo URL과 브랜치를 입력하는 폼으로 분석을 요청하**,
so that **API를 직접 호출하지 않고도 화면에서 바로 분석을 시작할 수 있다**.

## Acceptance Criteria

1. `/analysis` 페이지에 repo URL 입력 필드와 선택적 브랜치 입력 필드가 있는 폼이 있다.
2. 폼 제출 시 `POST /api/analysis`가 호출되고, 성공 시 새 Job이 목록에 나타나고 상태 폴링이
   시작된다.
3. 잘못된 URL 제출 시(400) 서버 에러 메시지가 화면에 표시된다.
4. 이미 진행 중인 동일 repo 요청 시(409) 사용자에게 안내 메시지가 표시된다.

- **Per-AC verification:** AC#1 → 폼 렌더 테스트; AC#2 → mutation mock 성공 시 목록/폴링 갱신

**진행 요약:**
- **Dev Notes와 실제 3.5 구현 간 설계 괴리 해결:** Dev Notes는 "3.5의 목록 쿼리를
  invalidate"를 가정했지만, 실제 3.5의 `/analysis` 목록은 TanStack Query가 아니라 Server
  Component가 직접 Prisma로 조회하는 구조였다. 그래서 invalidate 대신 `next/navigation`의
  `router.refresh()`를 성공 콜백에서 호출해 서버 컴포넌트 목록을 재검증하는 방식으로 구현했다.
  [Learning]
- "상태 폴링이 시작된다"(AC#2)를 만족시키기 위해, 제출 성공한 `jobId`를 컴포넌트 로컬 상태로
  들고 3.4의 `useAnalysisJob()`을 폼 컴포넌트 안에서 바로 사용해 방금 요청한 Job의 상태를
  실시간으로 보여준다 (배지로 표시). 이를 위해 `hooks/useAnalysisJob.ts`(3.4 소유)에 선택적
  `{enabled}` 옵션을 추가했다 — jobId가 아직 없을 때 쿼리가 실행되지 않도록 하기 위해 필요한
  최소 확장. [Learning]
- 400/409는 커스텀 `AnalysisRequestError(message, code)`로 던져서 `mutation.error`에서 구분:
  `DUPLICATE_REQUEST`는 고정 안내 문구, 그 외는 서버 `message` 그대로 표시.
- **테스트 인프라 신규 도입:** 이 프로젝트에 실제 상호작용(폼 입력/제출/에러 렌더) 테스트가
  필요해져서 `jsdom` + `@testing-library/react` + `@testing-library/user-event`를 처음
  설치함. 파일 상단에 `// @vitest-environment jsdom` 지시어로 이 테스트 파일만 jsdom
  환경에서 돌게 하고, 나머지 테스트(Neon DB 대상)는 기존 `node` 환경 그대로 유지. **주의:**
  `@testing-library/react`는 Vitest에서 자동 cleanup이 안 돼서 `afterEach(cleanup)`을
  명시적으로 호출해야 함 (안 하면 이전 테스트의 DOM이 남아 `getByPlaceholderText`가 여러 개
  매치되어 실패함). [Learning]
- 테스트 4건 추가 (렌더/성공+폴링/400/409). 전체 스위트 92건 통과. `npm run build`/`lint`
  통과.

**후속 스토리를 위한 참고:**
- 다른 스토리에서도 실제 폼 상호작용 테스트가 필요하면 이번에 세팅한 jsdom +
  testing-library 패턴(`// @vitest-environment jsdom` + `afterEach(cleanup)`)을 그대로
  재사용하면 된다.
